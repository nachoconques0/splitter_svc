# Issue tracker

Issues, specs and tickets for this repo live as **local markdown** under
`.scratch/<feature>/`. There is no external tracker.

- Specs: `.scratch/<feature>/spec.md`
- Tickets: one file per ticket, `.scratch/<feature>/<nn>-<slug>.md`

Triage state is recorded in each file's frontmatter under `labels:`. The
vocabulary in use is the canonical set; `ready-for-agent` means the item is
specified well enough to be picked up without further interview.

PRs are not a request surface for this repo.
